# mezashi

衛星・航空画像から物体を自動検出するツールです。  
飛行機・船・車両・インフラ施設など **15 種類** のオブジェクトを、**ブラウザだけで** 検出できます。インストール不要。

---

## できること

画像をブラウザにドラッグ＆ドロップするだけで、写っているオブジェクトを自動的に囲んで一覧表示します。

| 検出できる物体 |
|---|
| 飛行機 / 船 / 貯蔵タンク / ヘリコプター |
| 橋 / 港湾 / ラウンドアバウト |
| 大型車両 / 小型車両 |
| 野球場 / テニスコート / バスケットボールコート / 陸上トラック / サッカー場 / プール |

対応画像形式は **GeoTIFF**（`.tif` / `.tiff`）と一般的な画像ファイル（`.png` / `.jpg` など）です。  
GeoTIFF の場合は検出結果に地理座標（緯度・経度）も付与されます。

---

## 使い方（ブラウザアプリ）

1. `mefront/` フォルダに移動し、以下を実行してローカルサーバーを起動します。

   ```bash
   pnpm install
   pnpm dev
   ```

2. ブラウザで表示された URL（例: `http://localhost:5173`）を開きます。
3. 衛星・航空画像をウィンドウにドラッグ＆ドロップします。
4. 検出結果が画像上に重ねて表示されます。

> **注意:** 推論時はすべてブラウザ内で完結します。画像がサーバーにアップロードされることはありません。

---

## しくみ（技術概要）

```
衛星・航空画像
    ↓ ブラウザで読み込む
YOLO OBB モデル（ONNX 形式）
  ↓ ブラウザ上の AI ランタイム（ONNX Runtime Web）で推論
検出結果（バウンディングボックス＋クラス＋信頼度）
    ↓ 画面に表示 / CSV エクスポート
```

- **YOLO OBB（Oriented Bounding Box）**: 回転した矩形で物体を囲む検出アルゴリズム。斜めに写った物体も正確に検出できます。
- **ONNX Runtime Web**: AI モデルをブラウザ内で動かすための実行環境。サーバー不要。
- **DOTA データセット**: 世界規模の航空画像データセット。このモデルはそのデータで学習されています。
    - 利用時はライセンスにご注意ください。

## リポジトリ構成

| フォルダ | 役割 |
|---|---|
| `mefront/` | ブラウザアプリ本体（React + TypeScript） |
| `medetect/` | AI モデルの学習・エクスポート用スクリプト（Python） |

通常の利用では `mefront/` だけを使います。  
`medetect/` は独自データでモデルを再学習したい場合に使用します。
