# mezashi

mezashi は、衛星・航空画像から物体を検出するブラウザアプリと、モデルを準備するための Python ツール群を含むリポジトリです。推論はブラウザ内の ONNX Runtime Web で実行されるため、読み込んだ画像はアプリのサーバーへ送信されません。

## 主な機能

- GeoTIFF (`.tif` / `.tiff`) と一般的なラスター画像を読み込み
- ONNX 形式の YOLO 検出・YOLO OBB モデルをブラウザで実行
- 回転矩形（OBB）、ラベル、推定方向の表示
- 信頼度しきい値による結果の絞り込みとクラス別件数の確認
- 通常画像は JSON、位置情報を持つ GeoTIFF は GeoJSON で結果をダウンロード
- モデルメタデータ JSON の URL を切り替え、モデル・ラベル・入力サイズを変更

検出できるクラスは、選択したモデルのメタデータに含まれる `labels` によって決まります。モデルの利用条件はアプリに表示される各モデルのライセンス情報を確認してください。

## 使い方

Node.js 24 LTS と pnpm を用意してから、次を実行します。

```bash
cd mefront
pnpm install
pnpm dev
```

表示されたローカル URL をブラウザで開き、以下の手順で実行します。

1. 必要に応じて、モデルメタデータ JSON の URL を入力して適用します。
2. 画像をドラッグ＆ドロップするか、ファイル選択で読み込みます。
3. GeoTIFF 以外の画像では、地上サンプル距離（GSD、m/px）を入力します。
4. 画像上の検出結果を確認し、信頼度しきい値や表示項目を調整します。
5. 結果パネルから JSON または GeoJSON をダウンロードします。

## ライセンスとデータセット

モデルや学習データセットには、リポジトリ本体とは別の利用条件が適用されることがあります。特に DOTA に由来するモデル・データを利用する場合は、[DOTA の利用条件](https://captain-whu.github.io/DOTA/dataset.html) とモデルメタデータのライセンス欄を確認してください。
